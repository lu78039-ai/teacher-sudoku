# 尋找班導

以像素班導頭像為主角的格子邏輯遊戲，提供 149 道唯一解關卡，最大 10×10，支援教室 4K 寬螢幕、手機與平板。

## 開始遊玩

直接用瀏覽器開啟根目錄的 `index.html`（會自動進入遊戲），或開啟 `dist/index.html`，無需安裝套件。也可執行 `node server.cjs`，開啟 http://127.0.0.1:4173。

## 規則與操作

- 每行、每列、每個色區恰好有一位班導；彼此不能相鄰，包含斜對角。
- 單擊標記 ×，雙擊找出班導；按住滑鼠或手指滑過可連續標記 ×。
- 拖曳不覆蓋已找到的班導，一次復原可撤回整段拖曳。
- 找錯位置會顯示心碎動畫與紅色 ×；犯錯三次即失敗。復原不退還犯錯次數，重來會歸零。
- 過關後顯示班導跳舞與隨機讚賞詞，持續五秒，自動進入下一關。
- 可用下拉選單直接選擇任一關；完成最後一關會顯示全部通關訊息。

## 題目與驗證

原始 24 關、第 25–48 關刪去法題組、第 49–148 關推理題組，全部具有唯一解。新增題組另驗證區域連通、可用候選刪去法解出，以及旋轉、鏡射、換色後不重複。

- `node verify.cjs`：檢查關卡、操作、犯錯、存檔、慶祝、晉級與頭像。
- `node generate.cjs`：重建原始題組，保留後續題組。
- `node expand-levels.cjs`：重建第 25–48 關，保留其他題組。
- `node add-100.cjs`：保留前 48 關，重建後續 100 關，需 `seed-9.json` 與 `deduction.cjs`。
- `puzzle-design-report.json`、`reasoning-100-report.json`：題目檢查與推理證明。

## 發佈

將 `dist` 內的 `index.html`、`style.css`、`app.js`、`levels.js` 與整個 `assets` 資料夾上傳至 GitHub Pages 或其他靜態網站空間。`assets/teacher-pixel-avatar.png` 是透明背景的像素班導頭像。

進度保存在各裝置的瀏覽器，裝置之間不會同步；存檔支援既有版本的進度。Google Fonts 無法載入時會使用系統字型。

第三次犯錯會跳出隨機鼓勵彈窗，共 10 句帶有悲傷、吐槽與玩笑的詞句；可選擇重新挑戰同一關，或查看棋盤。

根目錄的 `index.html` 是入口，會自動前往 `dist/index.html`，可讓整個專案以 GitHub Pages main / (root) 發佈。另提供「尋找班導-GitHub發布版.zip」，解壓後直接將其中檔案放在儲存庫根目錄即可，無須 dist 資料夾。

Mobile UI V1.0 已恢復「提示」功能，可從工具列使用。

過關圖片使用 `assets/teacher-pixel-victory.png`：全身像素班導，張開雙手、抬腳跳舞，透明 PNG；棋盤仍使用 `teacher-pixel-avatar.png`。

滑動時，空格標記白色圓頭粗體 ×；既有 × 第一次被滑過時保留，下一次再滑過才清除，不比對路徑或時間。同一次滑動每格只處理一次，交叉或折返不會重複切換。單擊既有 × 仍立即清除。保留班導與紅色錯誤 ×，整段操作與交叉次數可一次復原。


## Mobile UI V1.0（feature/mobile-ui 候選版）

手機與平板（視窗寬度 1099px 以下）分成首頁與遊戲頁。首頁提供介紹、規則與「開始挑戰」，進入後改為精簡 App Bar、關卡選單、遊戲狀態、棋盤與四個操作按鈕。返回首頁不會重設本局，首頁暫停計時；重新載入保留進度。

新增 `dist/mobile.css`、`dist/mobile-ui.js`，發佈時必須一併上傳。所有路徑維持相對路徑，正式入口仍為 `/dist/index.html`，未加入 PWA。桌面維持原有三欄版面。

驗證指令：`node verify.cjs`、`node verify-mobile.cjs`。測試結果與修改前後截圖見 `qa/mobile-ui/REPORT.md`。這是待確認的本機功能分支，尚未合併或部署到正式站。


## 互動改善 V2（候選版）

- 點選只更新變動格子，保留棋盤節點與選關選項；滑動結束才寫入本次存檔。
- 格子滑過、按下、聚焦、顯示班導時都保留區域原色；透明頭像不覆蓋底色。
- × 改用圓頭交叉線，錯誤 × 保持紅色。
- 取消單格色區的數量限制，允許多個單格色區。既有 148 關完整保留，第 149 關新增 10×10 唯一解示例。
- `node add-ten.cjs` 可在沒有 10×10 關卡時附加示例，重複執行不會重複新增。
- 執行 `node verify.cjs`、`node verify-mobile.cjs`、`node verify-interactions.cjs`；實測數據與截圖見 `qa/interaction-v2/REPORT.md`。

仍在 `feature/mobile-ui` 等待確認，尚未合併或發布到正式站。

### 觸控與提示 V4

修正手機格子將指標捕捉轉交棋盤時，失去捕捉事件冒泡而提前結束滑動的問題。單擊立即顯示 ×；快速第二次點擊改為班導，拖曳仍立即標記。5×5、6×6 不顯示提示；7×7 至 10×10 每局最多提示 3 次，按鈕顯示剩餘次數，用完停用。次數隨遊戲存檔保存，復原不退還次數；重來或換關時重設。

### 手機一畫面與原生觸控 V5

首頁與遊戲頁依 100dvh 可用高度及手機寬度調整；棋盤同時受可用長寬限制，保持正方形。觸控裝置以非被動的 touchstart/move/end/cancel 處理手指手勢，滑鼠與觸控筆仍使用 Pointer Events；同一手勢不重複走兩套流程。提示以本關答案總數至少 7 個為開放條件，每局最多 3 次。

### 即時單擊 V6

移除 300ms 單擊等待。放開手指後立即標記 ×，快速第二次點擊時取代第一下操作並放置班導，整次雙擊只需一次復原。為保留即時回應，雙擊過程第一下會短暫顯示 ×。

## QA、排序與螢幕保持亮屏

關卡由小方陣開始，同尺寸以推理複雜度估計排序。原始題目索引不變，舊進度仍對應同題。每一錯格每局只計錯一次；清除或復原後再點不多扣。遊玩時可申請螢幕保持亮著，設定中可關閉，系統省電政策仍可能限制。

開發檢查：node scripts/audit-levels.cjs、node scripts/prepare-pwa.cjs、node verify-all.cjs。PWA 使用 HTTPS 或 localhost；直接開 file:// 仍能遊玩，但不能安裝或註冊 Service Worker。

PWA 安裝/部署步驟與實測限制見 [PWA-INSTALL.md](PWA-INSTALL.md)，QA 結果見 [qa/audit/REPORT.md](qa/audit/REPORT.md)。候選分支未直接發佈正式站。
