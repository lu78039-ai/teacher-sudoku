# 汪汪數獨 · Dog Sudoku

直接用瀏覽器開啟 `dist/index.html` 即可遊玩，無需安裝套件。亦可執行 `node server.cjs` 並開啟 http://127.0.0.1:4173。

48 道唯一解題目，5×5、6×6、7×7、8×8 各 12 題。每行、每列、每區域恰好一隻狗，狗不能相鄰（含對角）。支援排除記號、右鍵記號、復原、提示、計時、自動存檔與手機版面。

`node generate.cjs` 重新產生並驗證題目；`node verify.cjs` 檢查互動邏輯。自動存檔依瀏覽器與來源而定，使用本機伺服器時較穩定。Google Fonts 無法載入時會使用系統字型。

操作：單擊標記 ×，雙擊放小狗；按住滑鼠或手指拖曳可連續標記 ×，保留已有的小狗，整段拖曳可一次復原。

新增第 25–48 關為 ✦ 刪去法題組：每個色區至少兩格，逐題通過唯一解、區域連通、旋轉鏡射去重及免猜候選刪去求解驗證。執行 `node expand-levels.cjs` 可重新產生新增題組，需同資料夾的 `deduction.cjs`；`puzzle-design-report.json` 為設計檢查報告。

新增第 49–148 關為 100 題推理題組，涵蓋 5×5、6×6、7×7、8×8 與 9×9；每種難度合計 37 關。`node add-100.cjs` 會保留前 48 題並重建這 100 題；`reasoning-100-report.json` 保存每題刪去法證明與推理標籤。標籤是實際候選刪除步驟的分類，不代表每題包含所有進階策略。
