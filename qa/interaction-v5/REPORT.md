# 手機一畫面與觸控 V5

候選分支 feature/mobile-ui；未合併、未發佈正式版；關卡資料與玩家既有進度保留。

## 修改

- 首頁依可用高度縮減頭像、字級與留白；矮螢幕省略重複介紹，保留標題、規則、開始按鈕。
- 遊戲棋盤寬度取手機可用寬度與扣除導覽/工具列後高度的較小值，保持方格正方形；保留安全區。
- 支援原生觸控的裝置使用 touchstart/move/end/cancel（passive:false），避免依賴格子/棋盤之間的 pointer capture 轉交。同時忽略該手勢的 Pointer Events 和相容 click，防止重複結束或重複標記。滑鼠與筆保留 Pointer Events。
- 單擊、雙擊、交叉保留一次、再穿越清除、復原整段等規則保留。
- 提示依本關答案總數至少 7 個開放，最多 3 次；存檔保存用量，復原不補回。
- 更新資源版本 touch-v5，以重新載入新版 CSS/JS。

## 驗證

- verify.cjs、verify-mobile.cjs、verify-interactions.cjs、verify-native-touch.cjs 全部通過。
- 原生觸控事件回歸測試包含 5×5 至 10×10 的連續滑動、重複 pointerup/cancel/lostcapture 不干擾、整段復原、雙擊不閃 X、取消安全；測試禁止呼叫指標捕捉 API，確保手指路徑沒有依賴。
- 瀏覽器 360×640、360×800、390×844、412×915、844×390：首頁 5 組與各棋盤尺寸 30 組共 35 組檢查通過，無橫向/縱向溢出，棋盤完整，單格寬高誤差小於 0.1px，訊息與操作位於視窗內。
- 瀏覽器實際拖曳 7×7 第一行連續標記 7 格；截圖 game-fit.png、home-fit.png。尺寸紀錄 viewport-results.json。
- 桌面 1920×1080：10×10 棋盤 885.864px 正方形，無橫向溢出；無擷取到 JavaScript error。

限制：原生手指事件以測試程式模擬，瀏覽器實際拖曳使用滑鼠；尚未以實體手機確認。若測試正式網址，必須先部署候選內容，目前正式站不會自動更新。
