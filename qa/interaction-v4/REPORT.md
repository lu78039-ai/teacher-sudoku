# 手機觸控與提示 V4

分支 feature/mobile-ui，未合併 main，未發佈。

## 修正

- 手機 pointer capture 從格子轉交棋盤時，格子的 lostpointercapture 會冒泡。舊版直接結束整段拖曳，新版僅在棋盤本身失去捕捉時結束。原有逐格交叉計次保留。
- 單擊等待 300ms 區分雙擊，雙擊直接放置班導，取消暫時 ×。開始拖曳、換關或復原會取消待處理的單擊。
- 7×7（包含）以上才顯示提示，每局三次；5×5、6×6 隱藏。提示用量保存至既有存檔的新增 hintsUsed 欄位，舊存檔預設零，不更動棋盤資料與既有進度。復原不補回提示，重來/換關重設。

## 驗證

- node verify.cjs、node verify-mobile.cjs、node verify-interactions.cjs 全部通過。
- 149 題唯一解與遊戲狀態驗證；5×5 至 10×10 觸控事件及復原。
- 新增冒泡捕捉遺失事件回歸測試，整段滑動持續完成。
- 新增雙擊前棋盤不出現 ×、單擊切換、換關取消待處理事件測試。
- 新增各尺寸提示資格、三次上限、復原不退回、存檔計數測試。
- 瀏覽器 390×844：5×5 提示隱藏；拖曳連續標記四格、正確班導保持；7×7 三次提示後找到三位班導，按鈕為 0/3 且停用，重新整理後仍停用。
- 瀏覽器 1920×1080：相同提示限制，沒有擷取到 JavaScript error 日誌。
- 證據：phone-hint-limit.png、desktop-hint-limit.png。

限制：以手機視窗瀏覽器和模擬觸控事件驗證，尚未以實體 Android/iPhone 確認。單擊標記的 300ms 等待是避免雙擊閃 × 的辨識取捨。
